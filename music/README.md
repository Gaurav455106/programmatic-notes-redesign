# Music

Upload songs here (mp3, m4a, aac, wav or ogg). Every song in this folder plays on the site
automatically, on every device, in name order, then loops. No code change needed.

To upload on github.com: open this folder → **Add file → Upload files** → drop the songs → **Commit changes**.
The site picks them up about a minute later, after GitHub Pages redeploys.

Name files 1-..., 2-... to set the order. Delete a file here to remove it from the site.
Everything in this folder is public: anyone can download these files.
